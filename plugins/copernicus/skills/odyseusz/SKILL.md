# Odyseusz

Read [origins.md](references/origins.md) when explaining the method, changing
this skill, or applying it where deception, competition, negotiation, or
meaningful harm is possible.

## Aim

Find one move that changes the problem instead of merely applying more force.

Metis is not random creativity. It is practical intelligence for moving
terrain: attention, incentives, timing, information, identities, scarce
resources, and other actors. The result must expose a mechanism, not just sound
ingenious.

## Process

1. **TELOS** — State the legitimate desired outcome in one sentence. Name
   truth, consent, legal, safety, reputational, and relationship constraints.
   Do not optimize an unethical aim.
2. **TERRAIN** — Map only what changes the move: actors and incentives,
   bottleneck, asymmetry, timing window, information gap, available resources,
   and the opponent's or system's default expectation.
3. **DIRECT PATH** — State the obvious force-, money-, or effort-heavy approach.
   This is the baseline, not a straw man.
4. **TURN THE PROBLEM** — Generate a few mechanisms, then keep one:
   reframe the game, change sequence or timing, use indirection, recombine
   existing assets, substitute a scarce resource, make a reversible probe, or
   use an expectation without making a false claim. Preserve the user's stated
   scale and resources; do not invent an audience, access, budget, or numerical
   target. A mass blast, large scraped list, free event, more content, or hope
   of virality is still brute force unless a named mechanism changes the
   bottleneck. Require this proof: “This avoids a proportional increase in
   ___ because ___.” If it cannot be completed causally, reject the move.
5. **ETHICAL GATE** — Reject any move whose success requires fraud,
   impersonation, fabricated proof, coercion, non-consensual manipulation,
   illegal access, hidden harm, or a dark pattern. Cleverness is a capacity;
   the end and constraints decide whether it is good practical judgment.
6. **FIRST TEST** — Make the smallest cheap reversible test that could falsify the
   mechanism. Name the success signal, failure signal, and stop condition.
7. **FALLBACK** — Keep a direct honorable path if the clever move depends on an
   assumption that fails.

For marketing, find truthful distribution or positioning leverage rather than
fake scarcity or manufactured authority. For engineering, prefer a changed
boundary, invariant, sequence, or existing platform capability over another
layer. For research, seek a decisive proxy, contrast, or falsifier. For
negotiation, use incentives and options without misrepresentation.

## Produce

```text
TELOS
One legitimate outcome and its non-negotiables.

TERRAIN
The few asymmetries, constraints, and expectations that matter.

CLEVER MOVE
One concrete mechanism.

WHY IT WORKS
The assumption and leverage, stated causally.

FIRST TEST
A reversible action, success/failure signal, and stop condition.

RISKS
How the move could become brittle, deceptive, or harmful.

DIRECT FALLBACK
The honorable obvious path if the mechanism fails.
```

Do not call an ordinary good idea "Odysean" merely because it is novel. If no
ethical asymmetric move survives, say so and recommend the direct path.
Do not invent missing goals, assets, actors, or access to make a move seem
possible; state the missing assumption or ask for it when it is load-bearing.

This is a self-contained prompt workflow. It uses no scripts, services, private
project context, provider assumptions, or automatic actions.
